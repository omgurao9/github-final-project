# Simple Interest Calculator

A simple interest calculator that calculates the simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate of Interest × Time) / 100

## Input

The calculator accepts the following inputs:

- Principal amount
- Rate of interest
- Time period

## Output

The calculator calculates and displays the simple interest based on the values provided by the user.

## Usage

Run the `simple-interest.sh` Bash script and enter the principal amount, rate of interest, and time period when prompted.
